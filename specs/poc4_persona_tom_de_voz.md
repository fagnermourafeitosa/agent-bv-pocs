# PoC 4: Injeção de Persona e Tom de Voz (Voice Design)

## Objetivo
Estabelecer a "alma" do agente, garantindo que ele comunique os valores institucionais (simples, parceiro, seguro, inovador).

## Tarefas
- [ ] Escrever o *System Prompt* base estabelecendo as regras de tom de voz e taxonomia comportamental do Banco BV.
- [ ] Criar um endpoint isolado ou script local para testar a injeção do *System Prompt* no LangChain.
- [ ] Criar um conjunto de perguntas desafiadoras (ex: cliente irritado, solicitação fora das regras).
- [ ] Executar os testes e revisar manualmente se o agente foi empático, institucional e simples em suas respostas.
- [ ] Refinar o *System Prompt* com base nos erros iniciais e documentar as melhores práticas (Engenharia de Prompt).
